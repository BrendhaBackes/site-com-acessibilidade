Recursos da barra de acessibilidade

  • Alto contraste: muda para fundo preto, letras brancas e links amarelos.
  • Diminuir fonte, Aumentar fonte e Fonte normal: mudam o tamanho do texto em seis níveis, de 87,5% a 200%.
  • Ouvir esta página: o navegador lê o texto em voz alta. Você pode pausar e parar a leitura quando quiser. A leitura nunca começa sozinha.
  • VLibras: o botão azul no canto da tela abre um tradutor do texto para Libras. Ele é mantido pelo governo federal e precisa de internet.

O site lembra a sua escolha de contraste e de tamanho de letra nas próximas páginas.

Atalhos de teclado

Os atalhos usam a tecla Alt junto com um número. No Firefox, use Alt + Shift + número. No Mac, use Option + número.

Atalhos disponíveis em todas as páginas
AtalhoO que faz
Alt + 1Vai para o conteúdo principal
Alt + 2Vai para o menu
Alt + 3Vai para o rodapé
Alt + 4Liga ou desliga o alto contraste
Alt + 5Aumenta a fonte
Alt + 6Diminui a fonte
Alt + 7Volta a fonte ao tamanho normal
Alt + 8Começa ou para a leitura em voz alta
Alt + 0Abre esta página

Também funcionam as teclas de sempre: Tab para avançar entre links e botões, Shift + Tab para voltar e Enter para ativar.

Como apliquei o eMAG neste site

Escolhi tons claros para o site, mas cor bonita não basta: ela precisa ser lida por todo mundo. Por isso fui conferindo cada decisão com as regras do eMAG. Estas são as cinco que mais pesaram, cada uma com o erro comum e o que usei no código.

Links que dizem para onde vão

Um leitor de tela consegue listar todos os links da página. Se todos se chamam “clique aqui”, essa lista não ajuda ninguém. Por isso escrevi o destino dentro do próprio link.

Evite

<a href="tecnologia-assistiva.html">
  Clique aqui
</a>

Prefira

<a href="tecnologia-assistiva.html">
  Tecnologia assistiva
</a>

Imagens com texto alternativo

Quem não vê a imagem precisa saber o que ela mostra. Descrevi o que importa em uma frase curta no atributo alt, sem repetir o que o texto ao redor já diz.

Evite

<img src="images/principios-wcag.svg">

Prefira

<img src="images/principios-wcag.svg"
  alt="Quadro com os quatro princípios
  da WCAG: perceptível, operável,
  compreensível e robusto.">

Títulos em ordem

A tecla H do leitor de tela pula de título em título. Se eu pulasse do h1 direto para o h3, a pessoa perderia a estrutura da página. Em cada página usei um só h1 e desci um nível de cada vez.

Evite

<h1>Barreiras no acesso</h1>
<h3>Cegueira</h3>

Prefira

<h1>Barreiras no acesso</h1>
<h2>Cegueira</h2>
<h3>Como evitar</h3>

Contraste entre texto e fundo

O eMAG pede pelo menos 4,5 para 1. Medi as combinações do site e o texto principal chega a 13,97 para 1. Também nunca deixei a cor sozinha: a página atual no menu ganha negrito e fundo, além da cor.

Evite

color: #B9A89A;
background: #FBF7F2;
/* 2,16 para 1 */

Prefira

color: #33241B;
background: #FBF7F2;
/* 13,97 para 1 */

Foco visível no teclado

Quem navega com Tab precisa ver onde está. Em vez de esconder o contorno do foco, deixei um contorno grosso e com cor forte.

Evite

a:focus {
  outline: none;
}

Prefira

:focus-visible {
  outline: .22rem solid var(--foco);
  outline-offset: .2rem;
}

Como avaliar a acessibilidade

O eMAG recomenda combinar ferramentas automáticas com a avaliação manual. Estes são alguns passos e ferramentas, todos em outros sítios:

  1. Validar o código no validador de HTML do W3C.
  2. Percorrer a página só com o teclado e com um leitor de tela.
  3. Conferir o contraste no verificador de contraste da WebAIM.
  4. Rodar um avaliador automático, como o WAVE.

Os avaliadores automáticos não encontram todos os problemas. Por isso a checagem manual é indispensável.
